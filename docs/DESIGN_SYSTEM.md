# Design system

Warm paper, near-black type, one restrained blue accent, dark green Kept feature, and pale blue operational/research surfaces. The feature visuals are editorial typography, not screenshots or evidence of shipped interfaces.

## Tokens and scale

Paper `#f7f6f2`; ink `#202824`; muted `#59615b`; rule `#d8dad2`; accent `#294ec8`. Maximum composition width 1280px, fluid 20–72px gutters. Main section spacing 64–120px. Body 18px; supporting article details 16–17px. Paragraphs do not inherit the full composition width.

Hero name 64–152px with narrow-screen rules; interior headings 44–100px. Important actions 48–52px tall; supporting links have comfortable padding. System sans-serif with Georgia only for editorial emphasis; no external font requests.

## Interaction

Native page navigation and mobile disclosure. Native audio controls for seeking/volume with a single audio element for track selection. Native modal dialog with Escape and focus restoration. No autoplay, custom cursor, scroll hijacking, loading intro, canvas background, or permanent decorative animation.

Reduced motion disables CSS transitions. Core content and media fallback links remain available without JavaScript. Current-page navigation, visible focus, skip link, semantic landmarks, and a true 404 are part of the default system.

## Release review

Inspect actual portrait crops, all 31 photo/format variants, long names, narrow screens, zoom, keyboard behavior, screen readers, and mobile audio. Automated checks cannot judge personal image descriptions or portrait composition.
